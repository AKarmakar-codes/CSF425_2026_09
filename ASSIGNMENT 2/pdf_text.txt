3. Pseudo-Ground-Truth Protocol and Model Budget
Goal. A single, frozen YOLO26-L-seg + Segment Anything Model (SAM) pipeline will produce geometry-aware
pseudo-instance masks for evaluating compact student models. Treat these as reference pseudo-labels, not
human ground truth. The same instructor-controlled teacher, thresholds, class mapping, mask resolution and
evaluation images must be used for every group.
T1. 25-class detection. The YOLO26-L segmentation/detection head must first be adapted using only the 25-class
source data from Assignment–I (or paired with the same frozen 25-class source-trained classifier). Off-the-shelf
COCO-pretrained YOLO26 cannot automatically name all 25 specialized PCB classes. Retain each proposal’s
class ID, bounding box and confidence.
T2. SAM geometry refinement. Feed each retained component box (and, if justified, prompt points) to frozen
SAM. Extract the corresponding high-resolution binary mask. SAM supplies geometry, not a reliable PCB
class ID; inherit class identity only from the 25-class detector/classifier.
T3. Fixed annotation quality-control. Remove duplicate proposals with documented same-class mask-NMS,
discard obvious PCB-background artifacts using the provided whole-board mask, resolve overlap consistently,
preserve small resistor/capacitor instances and record uncertain regions as ignore=255. Never force a lowconfidence guess into a 25-class label.
T4. Versioned scoring reference. Use class_id, instance_id, bbox, score, and encoded mask per detected
component; unlabeled pixels use background 0 or ignored 255.
Permitted student use: Students may run YOLO26-L + SAM to illustrate or diagnose pseudo-masks on a separate,
designated public visualization subset and may use this teacher on source-domain training data. However, a student’s
self-generated DSLR reference labels are not accepted as that student’s grading ground truth. Teacher predictions
on the Instructor’s held-out DSLR evaluation set are reserved for scoring; no target-domain teacher-student fine-tuning or
threshold tuning is allowed for the graded zero-shot submission. Target pseudo-label fine-tuning, if investigated, must be
reported in a separate non-graded pseudo-supervised adaptation experiment.

Inference constraint. Your segmentation pipeline (i.e., backbone, class and mask heads, any decoder, and any other
learned auxiliary modules) must satisfy total parameters
Pi ≤ Pmax = P (YOLO26m-seg) ≈ 23.6 × 106 parameters.
