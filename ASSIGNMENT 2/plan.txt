## Architecture, Re-Engineering & Budget Target

* **Student Architecture**: Shared Compact **Mask2Former** (`ResNet-18` backbone + 4-scale Deformable/FPN Pixel Decoder with $1/4$-scale high-res fusion + 6-layer **Halo-Dilated Masked-Attention** Transformer Decoder, $Q=150, h=256$) supporting both Q1 (Semantic) and Q2 (Instance) from a single unified checkpoint.


* **Parameter Target**: $P_i = \mathbf{18.50\text{M}} \le 19.504\text{M}$ (hard ceiling $P_{\max} = P(\text{YOLO26m-seg}) \approx 23.6\text{M}$). Locks in the **maximum $E_i = 1.10\times$ efficiency multiplier**.


* **Three Substantive Internal Re-Engineering Mechanisms (Q1a & Q2 Rubric)**:


1. **Halo-Dilated Masked Attention (Silkscreen Context Reader)**: In each Transformer Decoder layer, apply a parameter-free $5\times 5$ max-pool morphological dilation ($\mathcal{D}_{5\times 5}(M_{l-1})$) to the attention mask feeding the classification cross-attention projection while retaining the tight un-dilated mask $M_{l-1}$ for mask refinement. This lets each query read adjacent white silkscreen designators (`U` vs. `IC`, `SW` vs. `S`, `R` vs. `C`) printed just outside the component body.


2. **Seesaw Loss for 25-Class Long-Tail Mitigation**: Replace standard uniform Cross-Entropy ($\text{weight}_\varnothing=0.1$) with **Seesaw Loss** (mitigation factor $p=0.8$, compensation factor $q=2.0$) so frequent passives (`R`, `C`) do not suppress rare classes (`V`, `QA`, `M`, `CR`, `CRA`, `BTN`, `F`, `T`) into the no-object class $\varnothing$.


3. **Laplacian Boundary-Aware Mask Loss ($\mathcal{L}_{\text{boundary}}$)**: Combine Focal/BCE mask loss + Dice loss + multi-scale Laplacian edge loss ($\lambda_{\text{bnd}}=1.0$) on the $1/4$-resolution mask features to prevent adjacent $0402/0603$ passives from merging and keep large IC/connector interiors coherent.

1. **Ground-Truth Box + SAM (`vit_h`) Distillation on Graph-W & Graph-F**:

* **Graph-F (115 train boards)**: Use ground-truth XML boxes + `SAM (vit_h)` to split touching same-class 8-connected blobs (dense resistor/capacitor arrays) into distinct instance masks.


* **Rule T3 Quality Control**: Apply same-class Mask-NMS, sort instances by area ascending so small passives embedded on larger pads remain visible, and set low-confidence/ambiguous boundary pixels to `ignore = 255` and background to `0`.


* **Optional $1.5\times$ Rare-Class Source Supplementation ($A_i = 1.0$)**: Include up to 76 additional training boards from the parent FPIC/WACV-2019 source repositories containing under-represented classes ($r_i = \frac{N_{\text{distinct}}}{152} \le 1.50 \implies A_i = 1.0$, zero grading decay).

### Step 7: True Differentiable Grad-CAM (Q1d & Q2c)

Never substitute Transformer attention weights for Grad-CAM:

1. **Q1 Semantic Grad-CAM (Q1d — 3 Marks)**:


* Hook the Pixel Decoder's high-resolution spatial feature map `pixel_decoder.mask_features` ($1/4$ scale, $256 \times 256$ per tile) and `backbone.layer4`.


* Define target scalar $Y_{\text{sem}}^c = \sum_{(h,w) \in \Omega_c} S_c(h,w)$ for predicted class $c$, compute $\alpha_k^c = \frac{1}{HW} \sum_{h,w} \frac{\partial Y_{\text{sem}}^c}{\partial A_{h,w}^k}$, and render $\text{ReLU}\left(\sum_k \alpha_k^c A^k\right)$.


* Document in `README.md` how Halo-Dilated Attention causes Grad-CAM to highlight both the component body and adjacent silkscreen labels (`U`/`IC`, `R`/`C`), and analyze $\ge 2$ failure cases.
